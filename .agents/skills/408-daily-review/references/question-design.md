# 出题质量契约与 408 考纲口径规范

生成每日一练或专项练习时加载本文档。所有题目交付用户前必须全部满足以下规范。

---

## 1. 选题配比与题源结构

- **默认题量**：`3 道单选题 + 1 道大题`（大题可为纯 C 算法题、图论手算模拟题，或计组/OS/计网综合大题），整体耗时控制在 10–15 分钟。
- **状态准入**：
  - 允许抽取：`learned`、`weak`、`learning`。
  - 严禁抽取：`skipped`、`not_started`。
  - 对标记“潦草学过/已遗忘”的 `weak` 模块（如图论），先出小规模手算题与核心性质题温和回炉，待 `mastery >= 3` 再上高综合题。
- **遗忘曲线配比**（跨天近似）：
  - **60% 到期旧知识**：优先 `next_review <= today` 或低 `mastery` 的 `learned` / `weak` 考点。
  - **20% 历史错题变式**：从 `408/review/mistakes.md` 的「待变式回炉」抽取，必须**改换数据、图形拓扑、指针约定或反问视角**，禁止原题照搬。
  - **20% 近期新学知识**：从 `status == "learning"` 或近两日 `diary/` / `408/` 新增内容抽取。
- **题源锚定**：
  - **约 70% 早期真题（原题或同构改编）**：仅从 `review_cli.py status` 给出的 `Allowed pool` 中检索，并避开 `used_real_questions` 已做原题。
  - **约 30% 针对性补充题**：针对错题坑点或用户仓库代码（如 `408/DS/`）设计变式/追问。

---

## 2. 五条质量硬标准

1. **来源透明**：每题标题必须附带标准标签之一：
   - `[真题原题 · YYYY年 第X题]`
   - `[真题变式 · 参考YYYY年 第X题]`
   - `[考点自编 · 考点简称]`
2. **考纲边界与教材分歧显式消歧**：遇到不同教材口径不统一处，**必须在题干中显式写明定义**（见下表）。
3. **100% 程序独立验算**：凡涉及下标映射、树/图算法模拟、排序趟数、散列探测 ASL、补码/IEEE754、Cache/页表、PV/调度、子网/TCP 窗口或代码追踪的题目，**出题前必须运行 Python 或 C 小脚本核验唯一正解**。若改编题出现多解或无解，立即修正条件并重跑验算。
4. **干扰项有错因映射**：4 个选项中，3 个干扰项必须各自对应一个真实思维误区（如 off-by-one、方向反置、漏判空位/边界、混淆最坏与平均复杂度），严禁凑数项或文字游戏。
5. **零剧透呈现**：出题回合只展示题干、选项与作答指引，严禁附带答案、隐晦暗示或判题源码。

---

## 3. 408 常见教材口径分歧消歧表（出题必查）

| 模块 | 易歧义点 | 题干必须显式声明的信息 |
| :--- | :--- | :--- |
| 数组与矩阵压缩 | 数组与矩阵起始下标 | 矩阵元素是 $1 \le i,j \le n$ 还是从 $0$ 开始；一维数组 `N` 下标从 `0` 还是 `1` 开始；按行优先还是按列优先 |
| 栈与循环队列 | 指针语义（实位 vs 虚位） | `top` 初始为 `-1` 还是 `0`；`rear` 指向**队尾元素**还是**队尾元素的下一个位置** |
| 串与 KMP | `next` 数组基准 | 主串/模式串下标从 `1` 开始还是从 `0` 开始，必要时直接给出 `next[1]=0` 等锚点值 |
| 树与二叉树 | 树高定义 | 空树高度为 `0`、单根结点高度为 `1`（408 主流口径），若有特殊约定须写明 |
| B 树 / B+ 树 | 高度是否含外部失败结点 | 明确“高度不包含叶结点下的失败结点层” |
| 散列表（Hash） | 查找不成功 ASL 分母 | 明确对哈希函数 `H(key) = key % p`，“查找不成功 ASL 按 `0..p-1` 共 `p` 个初始散列地址等概率计算” |
| 排序 | 一趟排序的定义 | 快排明确枢轴选取位置；归并明确二路自底向上还是递归 |
