## 第 1 题 `[真题变式 · 参考2011年 第3题]`
已知循环队列存储在一维数组 `A[0..7]`（数组长度为 `8`，最多容纳 `7` 个元素）中，约定**队列非空时 `front` 指向队头元素，`rear` 指向队尾元素**。若当前队列非空且 `front = 5, rear = 1`，则当前队列中的元素个数，以及紧接着将新元素 `x` 入队的正确 C 语句序列分别是（ ）。
- A. `4` 个；`A[rear] = x; rear = (rear + 1) % 8;`
- B. `4` 个；`rear = (rear + 1) % 8; A[rear] = x;`
- C. `5` 个；`A[rear] = x; rear = (rear + 1) % 8;`
- D. `5` 个；`rear = (rear + 1) % 8; A[rear] = x;`

- **我的作答**：B（错）
- **正确答案**：D
- **核心拆解**：
  1. **入队语句**：`rear` 指向当前队尾元素（实位 `A[1]` 已占），故须**先移指针再存元素** `rear = (rear + 1) % 8; A[rear] = x;`（此点较昨日 M002 已掌握）。
  2. **元素计数**：`front = 5` 与 `rear = 1` 两端都是实有元素的**闭区间**，沿环形下标点数为 `A[5], A[6], A[7], A[0], A[1]` 共 **5** 个；通用公式为 `(rear - front + 1 + M) % M`，选 B 是惯性套用了虚位左闭右开公式 `(rear - front + M) % M`。

## 第 2 题 `[真题原题 · 2015年 第5题]`
设有向图 $G = (V, E)$，顶点集 $V = \{v_0, v_1, v_2, v_3\}$，有向边集 $E = \{\langle v_0, v_1 \rangle, \langle v_0, v_2 \rangle, \langle v_0, v_3 \rangle, \langle v_1, v_3 \rangle\}$。若从顶点 $v_0$ 开始对图进行深度优先遍历（DFS），则可能得到的不同遍历序列个数是（ ）。
- A. `2`  B. `3`  C. `4`  D. `5`

- **我的作答**：认为是 6 种（错）
- **正确答案**：D（`5` 种）
- **核心拆解**：
  1. $v_0$ 的 3 个出边邻接点 $\{v_1, v_2, v_3\}$ 在邻接表中确实有 $3! = 6$ 种排列，但存在有向边 $\langle v_1, v_3 \rangle$。
  2. 当第一步从 $v_0$ 走到 $v_1$ 时，$v_3$ 尚未被访问，DFS 必须优先深入访问 $v_3$，回溯后才轮到 $v_2$。因此邻接表顺序 `(v1, v2, v3)` 与 `(v1, v3, v2)` 产出同一条序列 `v0, v1, v3, v2`（`v0, v1, v2, v3` 是 BFS 序列，非法），故共有 $6 - 1 = 5$ 种。

## 第 3 题（补位题） `[真题原题 · 2014年 第2题]`
> 原第 3 题（2019-Q8 散列表）因尚未学到散列表已退回题池（零剧透保留），`ds_search_hash` 已同步改为 `not_started`。

假设栈初始为空，将中缀表达式 `a/b+(c*d-e*f)/g` 转换为等价的后缀表达式的过程中，当扫描到 `f` 时，栈中的元素（按栈底到栈顶顺序）依次是（ ）。
- A. `+(*`  B. `+(-*`  C. `/+(*-*`  D. `/+-*`

- **我的作答**：算成 `/(*`（错）
- **正确答案**：B（`+(-*`）
- **核心拆解**：
  1. **核心直觉**：后缀表达式里**谁先输出谁就先算**。高优先级（或同级在左）的运算符左右操作数一凑齐就必须**先弹栈输出去计算**；低优先级的运算符还要等右边算完，所以**留在栈底等待**。
  2. 逐步状态：扫 `/` 入栈 `/`；扫 `+` 时栈顶 `/` 优先级更高，弹出 `/`、压入 `+`（栈 `+`）；扫 `(` 入栈（栈 `+(`）；扫第一个 `*` 入栈（栈 `+(*`）；扫 `-` 时栈顶 `*` 优先级更高，弹出 `*`（遇 `(` 停）、压入 `-`（栈 `+(-`）；扫第二个 `*` 优先级高于栈顶 `-`，直接入栈（栈 `+(-*`）；扫操作数 `f` 直接输出，栈保持 `+(-*`。
